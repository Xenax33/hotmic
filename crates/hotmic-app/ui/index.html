Set up Hotmic

Four checks. Green means ready.

  1. VB-Cable installed
    Open the VB-Cable download page
  2. Windows output is your headset, not the cable
  3. Engine running into CABLE Input
  4. Discord: Input Device set to CABLE OutputUser Settings, Voice & Video, Input Device. Krisp noise suppression will thin out music clips; speech clips pass.
